Car pictures
============
Put one picture per car in this folder. The file name is the car name in lower case,
spaces replaced by "-", with .jpg / .jpeg / .png:

    byd-leopard-8.jpg
    fsr.jpg
    sino-cassoni.jpg      (all three are already included)

The bot uploads the picture to Telegram the first time the car is opened and remembers it.
If you replace a picture later, send the new one to the bot as an admin with the caption
/setphoto <car id>   (see /cars for the ids).
